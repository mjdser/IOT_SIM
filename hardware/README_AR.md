# تشغيل المشروع على الـESP32 الحقيقي

هذه نسخة جاهزة للتجربة الأولى على القطعة. البناء وفحوصات الكمبيوتر نجحوا، لكن
الاتصال ونقل البكسلات واللمس لم يُفحصوا على لوحة حقيقية بعد.

1. فك ضغط المجلد بالكامل. ثبّت Python 3.12 مع إضافته إلى PATH.
2. من مجلد المشروع شغّل:
   `python -m pip install platformio pyserial opencv-python`
3. انسخ `.env.example` إلى `.env` وضع مفتاح Gemini الخاص بك.
4. أغلق أي برنامج يستخدم COM أو سيرفر قديم على 8765.
5. شغّل `Start-Hardware.cmd` ووصل الـESP32 المرتبط بالشاشة عبر USB.
6. أول مرة فقط: اختَر المنفذ في قسم First connection واضغط Install capture
   firmware ووافق على استبدال البرنامج الموجود على اللوحة.
7. انتظر ظهور الصورة من اللوحة. اكتب طلبك في الشات الموجود بجانبها.

الكود والتستات يعملان على الـESP32؛ الكمبيوتر يعرض نسخاً دورية من البكسلات.
هذه ليست كاميرا وليست محاكاة CPU. أول تثبيت يعرض مثال ترصيص العجلات المحفوظ.
لا يوجد تحميل تلقائي بمجرد وصل جهاز غير معروف. الطلبات التالية بالشات تحمل
الواجهة الجديدة على اللوحة التي تم التعرف عليها وتنفذ الاختبارات عليها.

اقرأ `hardware/README.md` للتفاصيل وحدود التصوير وقائمة أول فحص فعلي.
لا يحتوي الملف على API keys أو سجل محادثات. لا تشارك `.env` بعد تعبئته.
